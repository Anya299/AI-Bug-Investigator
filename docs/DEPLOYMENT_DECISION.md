# Deployment Decision

## Selected Platform

Render

## Why Render?

AI Bug Investigator is mainly a portfolio and hiring-manager demo project.

Render was chosen because:
- It provides a stable public demo URL.
- It is suitable for portfolio projects.
- It avoids dependency on limited monthly credits.

## Alternative Considered

Railway:
- Faster startup time.
- Good developer experience.
- However, free credits can run out and the service may stop.

## Final Decision

Render will be used because the main goal is to keep AI Bug Investigator available for demos, interviews, and portfolio reviews.
